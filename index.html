Empty Except and Broad Except

The README says the tool detects instances of empty except blocks or generic exception handling. Such handling might mask underlying issues or security vulnerabilities. It can prevent proper error handling and lead to unexpected behaviour.

One Tool per Run

One run uses one tool only. A full picture needs four separate runs, and the caller must line up the four outputs by hand. Bandit runs with recursive search and plain text output. Flake8 keeps the bare except check E722 in its selection. Pylint keeps the bare and broad except warnings W0702 and W0703 out of its disable list. Pyre runs as pyre analyze with the path as an argument.

A None Result Fails the Run

A result of None means failure and the run exits 1. A missing path also ends the run at 1.

An Empty Report Can Mean a Clean Run

An empty string means a clean tool run. An empty report then prints and the run exits 0.
